# /elokuvat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an `elokuvat` plugin. Its `/elokuvat` skill shows tonight's screenings (default) or this week's films in any Finnish city that elokuviin.com covers, as a terminal table and as a filterable web page.

**Architecture:** One script, `elokuvat.py`, reads elokuviin.com (showtimes, from the page's `__NEXT_DATA__` JSON) and nytleffaan.fi (premiere dates and age ratings), joins them, and prints the whole week as JSON. `sivu.py` turns that JSON into the markdown table for the chosen window (tonight, tomorrow or the week) and fills the HTML template, which always holds the whole week. `asetukset.py` saves the default city and window. `SKILL.md` ties it together. It is modelled on `plugins/nayttelyt/`.

**Tech Stack:** Python 3.11+ standard library only (`urllib`, `json`, `re`, `html`, `zoneinfo`), plain HTTP, no browser. The page is a single HTML template with inline CSS and JS. Tests use `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-16-elokuvat-design.md`

## Global Constraints

- Command, plugin and folder names are `elokuvat` (ASCII). Nothing under `plugins/keikat/` or `plugins/nayttelyt/` changes.
- Scripts are self-contained (no imports between them, since `python3 -I` can't import siblings) and run with `python3 -I`. Tests load them with `importlib`, like `plugins/nayttelyt/skills/nayttelyt/tests/test_sivu.py`.
- `SKILL.md`, script messages and page text are in Finnish. README and the marketplace entry are in English.
- License Apache-2.0, author "Jouni Uusimaa".
- Read only `https://elokuviin.com/<city>` and `https://nytleffaan.fi/paikkakunta/<city>/`. Never `elokuviin.com/api/` (robots.txt) and never `finnkino.fi`.
- A failing source prints one line to stderr, is marked `"ok": false` in `sources`, and the script still exits 0. Showtimes are never guessed.
- All times shown are Europe/Helsinki. elokuviin.com gives UTC (`...Z`).
- Settings go in `$XDG_CONFIG_HOME/elokuvat/asetukset.json` (default `~/.config/elokuvat/`). Factory defaults are `{"kaupunki": "Oulu", "aikavali": "tanaan"}`.

## Shared data shape (all tasks)

`elokuvat.py` prints, and `sivu.py` reads:

```json
{"city": "Oulu", "title": "Elokuvat Oulussa", "generated": "2026-11-16T17:40",
 "from": "2026-11-16", "to": "2026-11-22",
 "screenings": [{"start": "2026-11-16T19:40", "film": "f1", "cinema": "Finnkino Plaza",
                 "auditorium": "Sali 1", "url": "https://www.finnkino.fi/liput/…", "note": ""}],
 "films": [{"id": "f1", "title": "Lapin sota", "original": "Lapin sota", "runtime": 158,
            "genres": ["Draama", "Sota"], "premiere": "2026-10-23", "age": "12",
            "url": "https://elokuviin.com/elokuvat/lapin-sota", "tags": []}],
 "sources": [{"name": "elokuviin.com", "url": "https://elokuviin.com/oulu", "ok": true},
             {"name": "nytleffaan.fi", "url": "https://nytleffaan.fi/paikkakunta/oulu/", "ok": true}],
 "warnings": []}
```

- `screenings[].film` is a `films[].id`. `start` is local time without seconds or zone. `note` holds the festival name, or `Ulkoilma` for outdoor screenings, else `""`.
- `runtime` is an int or `null`. `premiere` is an ISO date or `""`. `age` is a string like `"7"`, `"S"` or `""`.
- `generated` is the local time the script ran. `from` is today and `to` is this Sunday.
- When elokuviin fails, `screenings` is `[]` and `films` comes from nytleffaan (ids `n0`, `n1`, …, with `runtime: null`, `genres: []`).

## Order

Task 1 and Task 2 are independent. Task 3 needs Task 2's JSON shape (above), not its code. Task 4 needs Task 3. Task 5 needs Tasks 1–4.

## Review Focus

1. **A city whose name has ä/ö** (Jyväskylä, Hämeenlinna, Seinäjoki): elokuviin.com redirects the ASCII slug with 308, which `urllib` follows only on Python 3.11+. Build the URL from the lowercase name, percent-encoded (`jyv%C3%A4skyl%C3%A4`), so no redirect is needed. Tested in Task 2 (`slug`).
2. **Late evening "tonight"**: at 22:30, screenings that already started are dropped, and an empty result prints a table header plus the line `Ei enää näytöksiä tänään.` instead of failing. Tested in Task 3.
3. **A film whose `titleFI` is null**: it falls back to `title`, and the nytleffaan join still works on that title. Tested in Task 2.
4. **elokuviin.com down or its page changed** (no `__NEXT_DATA__`): the output still has a film list from nytleffaan, a warning naming elokuviin.com, and `ok: false`. Tested in Task 2.
5. **An unknown city** (`404` from elokuviin.com): the script exits 2 with `elokuviin.com ei tunne kaupunkia 'X'.` on stderr, so the skill can stop with one sentence. Tested in Task 2.

### Task 2: Source script `elokuvat.py`

**Files:**
- Create: `plugins/elokuvat/skills/elokuvat/scripts/elokuvat.py`
- Create: `plugins/elokuvat/skills/elokuvat/tests/test_elokuvat.py`

**Interfaces:**
- Produces (all in `elokuvat.py`):
  - `slug(city: str) -> str`: `urllib.parse.quote(city.strip().lower().replace(" ", "-"))`.
  - `fold(s: str) -> str`: join key. Lowercase, diacritics removed, every non-alphanumeric character removed (`"Late Lammas -elokuva: Hämäräpuuhissa"` → `"latelammaselokuvahamarapuuhissa"`).
  - `parse_elokuviin(page: str) -> dict`: returns `{"city", "inessive", "screenings", "films"}` in the shared shape (films without `premiere`, `age`, `tags`). Raises `ValueError("__NEXT_DATA__ puuttuu")` when the script tag is missing.
  - `parse_nytleffaan(page: str) -> list[dict]`: `[{"title", "premiere", "age", "url"}]`.
  - `is_new(premiere: str, today: date, to: date) -> bool`: `today - 7 days <= premiere <= to`; `False` for `""`.
  - `join(films: list, nyt: list, today: date, to: date) -> list`: adds `premiere`, `age`, `tags` (`["Uusi"]` or `[]`) to each film by `fold(title)`; a film with no match gets `""`, `""`.
  - `build(city: str, now: datetime, fetch=fetch) -> dict`: the whole shared JSON. Raises `CityNotFound` when elokuviin.com returns 404.
  - `fetch(url: str) -> str`: `urllib.request` with a browser-like `User-Agent` and `Accept-Language: fi`, 20 s timeout, as in `nayttelyt_oulu.py:45`.
  - CLI: `elokuvat.py --city NAME [--table]`. Exit 0 normally, 2 on unknown city.

Parsing details the tests pin:
- `__NEXT_DATA__` is `<script id="__NEXT_DATA__" type="application/json">…</script>`; data is under `props.pageProps`: `screenings[]` (`startsAt`, `movieId`, `cinemaId`, `auditorium`, `bookingLink`, `festival`, `outdoor`), `movies{id}` (`titleFI`, `title`, `runtime`, `genres[].name`, `slug`), `screeningCinemas{id}.name`, `cityObject.name` / `.nameInesive`.
- Film `title` is `titleFI or title`; `url` is `https://elokuviin.com/elokuvat/<slug>`. Screening `url` is `bookingLink` or `""`; `note` is `festival["name"]` if `festival` is a dict, else `"Ulkoilma"` if `outdoor`, else `""`.
- nytleffaan card: `<div class='movie-card paikkakunta-page-movie-card'>` … `<h3>Title</h3>` … `src='https://nytleffaan.fi/data/icons/7.png'` (age = file stem, e.g. `7`, `S`) … `<span class='movie-card-premiere-date'>30.10.2026</span>` … `<a class='movie-card-movie-link' href='…'>`. Titles are HTML-unescaped.
- Fallback when elokuviin fails (any exception except 404): `films` from nytleffaan with `premiere <= to`, `screenings: []`, warning `elokuviin.com ei vastannut: näytösajat puuttuvat.`. nytleffaan failing gives warning `nytleffaan.fi ei vastannut: ensi-illat ja ikärajat puuttuvat.`.
- Weekend warning: if the window contains Friday–Sunday and earlier days too, and the average screenings per day for Fri–Sun is under half the average for the earlier days, add `Viikonlopun näytöksiä on vielä vähän: teatterit julkaisevat ne yleensä viikon loppupuolella.`.
- `--table` prints a plain text list (`ma 16.11. 19.40  Lapin sota  Finnkino Plaza`) for debugging only.

### Task 3: Table and page script `sivu.py`

**Files:**
- Create: `plugins/elokuvat/skills/elokuvat/scripts/sivu.py`
- Create: `plugins/elokuvat/skills/elokuvat/tests/test_sivu.py`

**Interfaces:**
- Consumes: the shared JSON shape.
- Produces:
  - CLI: `sivu.py in.json out.html [--tanaan | --huomenna | --viikko]` (default `--tanaan`). Writes the page and prints the markdown table. Exit 1 with a message on invalid input (a screening without `start`, `film` or `cinema`, `start` not `YYYY-MM-DDTHH:MM`, or `film` not in `films`).
  - `short_cinema(name: str) -> str`: drops a leading `Finnkino ` or `Elokuvateatteri ` (`"Finnkino Plaza"` → `"Plaza"`, `"Oulun Elokuvakeskus R.y."` unchanged).
  - `day_rows(data: dict, day: date, after: datetime | None) -> list[dict]`: screenings on `day`, starting at or after `after` when given, sorted by `start`.
  - `md_day(data: dict, rows: list, heading: str) -> str`: heading line, blank line, `| Klo | Elokuva | Teatteri | Sali | Kesto | Ikäraja | Liput |`. Klo is `19.40`; Elokuva is the title plus ` (Uusi)` when tagged; Kesto `158 min` or `–`; Liput `[Liput](url)` or `–`. With no rows, after the header: `Ei enää näytöksiä tänään.` (tonight) or `Ei näytöksiä.` (tomorrow).
  - `md_week(data: dict, heading: str) -> str`: `| Tagit | Elokuva | Kesto | Lajityyppi | Näytökset | Liput |`, one row per film that has screenings (or every film when `screenings` is empty, with Näytökset `–`). Näytökset: `Plaza: ma 17.15 19.40, ti 20.45 · Star: ke 18.30` (cinemas in order of first screening, days `ma`–`su`). Liput links the film's `url`. Order: `Uusi` first, then screening count descending, then title.
  - Headings: `Elokuvat Oulussa tänään 16.11.2026`, `Elokuvat Oulussa huomenna 17.11.2026`, `Elokuvat Oulussa 16.–22.11.2026` (from–to; `30.11.–6.12.2026` across months).
  - Page: template `templates/elokuvat.html` with `__TITLE__` (HTML-escaped title) and `__DATA__` (the JSON with `</` escaped as `<\/`), as in nayttelyt's `sivu.py`.
  - Tonight's cut-off is `generated`, not the clock, so output is reproducible.

**Interfaces:**
- Consumes: `__TITLE__`, `__DATA__` (shared JSON shape).

Behaviour the page must have:
- Day chips for every day `from`..`to` (`ma 16.11.`…). The chip for the viewer's today (by the viewer's clock) is selected on load; if today is outside the range, the first day.
- For the selected day: one card per film with screenings that day, showing title, Uusi badge, runtime, genres, age, and its times grouped by cinema. Each time is a link to `url` when present. - Filters: text search (title, original title, genres), cinema select, "Vain uudet" checkbox. A count line like nayttelyt's.
- When `screenings` is empty: list the films without times and show the first warning.
- `warnings` and `sources` (with links) at the bottom, like nayttelyt's notes and sources.
